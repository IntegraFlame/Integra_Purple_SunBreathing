The two Integra logo images, in color: a white "Integra" wordmark over the cyan-to-orange "Infinite Living Flame" tagline, with a soft glow on the tagline.

- `IntegraLogoCOLOR2026.png`: the original, lossless. Prefer it wherever the size suits.
- `BESTIntegraLogoCOLOR2026resized.jpg`: a larger resize, JPEG. Use it when a bigger image is needed.

Both have a black background baked in. Place them on `void` and never on `card` or a lighter ground. Both are full-color raster images, so they carry their own ink and are shown through `<img>`. Never recolor, stretch or redraw them; for text-only uses, set the wordmark live with the `wordmark` and `tagline` type styles (see `Logotype`).
